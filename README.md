# PEOS · SJY Personal Executive OS

> 个人执行操作系统 —— 本地只读驾驶舱。PRD 见 `PRD.md`。

## 启动

```bash
python3 server.py
# 浏览器打开 http://127.0.0.1:8790
```

零依赖（Python 3 标准库 + 原生前端），不需要 npm/pip 安装。

## 它是什么

把 Obsidian vault 里散落的自我规划系统聚合为一块驾驶舱屏幕：

| 页签 | 回答的问题 | 数据源（vault 只读，除勾选与日记段） |
|------|-----------|-------------------|
| 🚀 今日 | 今天要做什么、现在的第一优先级（交互式 Jarvis 引擎） | 今日 Daily Note + 判断顺序引擎 |
| ✅ 任务 | 所有任务（可勾选回写）、青蛙上午区 + 缓冲时间表、内容管道、近期截止 | 近 14 天 Daily + 内容排期表 + 入学时间线 |
| 📊 状态与差距 | 四象限现在多少分、离理想 5.0 差多少 | HUMAN3.0 四象限（config）+ 身体数据趋势 + 半年框架 |
| 📖 复盘 | 记日记 → AI 卡片流（emoji + 一句话摘要 + 评分 + 评价，点开看全文）；决策 Agent 聊天 | Daily「📖 今日日记」段读写 + agent_skill.md 规则 |

## ADHD 日程方案（已选 A+D）

- **A 时间块 + 缓冲 + 当前高亮**：任务页右栏时间表按时间排布，块间自动显示缓冲行，今天的表实时高亮"现在"块
- **D 青蛙 + 最低闭环 + 三档降档**：青蛙 = 最重要的事放上午做完（1–3 只，不是只做一件事）；精力 ≤2 或睡眠 <6.5h 时引擎自动给出低精力方案（删任务不压时间）

## 核心设计原则（继承 Jarvis 方案）

1. **本地优先**：不联网、不上传、不依赖外部服务
2. **vault 只读**：v1 绝不写 Obsidian（写回是 v2，且每次写前展示 diff 征求确认）
3. **文件是事实源**：每次刷新实时重读 markdown；站点只是渲染层
4. **不编造**：读不到的数据显示「待填写/暂无」，不填 0

## 可调参数（config.json）

- `quadrants`：四象限分数（当前口径 HUMAN3.0 v3，2026-04-29；建议重估后更新）
- `kpi_weekly`：周 KPI 目标与关键词（口径按 2026 秋半年框架拟定）
- `fitness`：12 周健身计划起始日与目标体重
- `semester`：半年目标清单与状态
- `port`：端口（默认 8790）
